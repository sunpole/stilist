# GitHub portfolio audit — 18 September 2026

## Scope and counting rule

This is a point-in-time inventory of the public repositories owned by
[`sunpole`](https://github.com/sunpole), checked against the Git repositories
found in the home-PC project archive. A project means a distinct repository or
canonical product; duplicate working copies, staging clones and backups do not
increase the product count.

## GitHub result

- **49** public repositories under `sunpole`.
- **6** repositories were newly published on 18 September 2026:
  `CreateZakFolder`, `rename`, `text-cleaner-pro`, `TranslitWidget`, `uCode`
  and `uTK`.
- Every new repository has a README, public source and an enabled GitHub Pages
  site. The Pages landing screens were checked in a browser.

of OCR/order-folder helpers with several copied script variants. Keep it in the
GitHub inventory; add it to the storefront after its canonical scope and visual
presentation are separated into one product card.
